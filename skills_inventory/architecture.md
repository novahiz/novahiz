# 🏗️ Architecture & Lead Dev

- **api-design-reviewer** : Revue et audit d'API REST / GraphQL.
- **cto-advisor** : Conseil technique, dette, passage à l'échelle, build vs buy.
- **cto-review** : Revue d'architecture avec focus sur la rentabilité/scalabilité.
- **database-designer** : Modélisation avancée SQL/NoSQL.
- **database-schema-designer** : Normalisation, diagrammes ERD, migrations.
- **feature-flags-architect** : Stratégie de bascules de fonctionnalités.
- **migration-architect** : Planification de migrations massives, stratégie rollback.
- **rag-architect** : Architecture de systèmes RAG (LLMs, embeddings, vecteurs).
- **saas-scaffolder** : Génération de SaaS Boilerplates complets (Next.js, Stripe, Drizzle).
- **senior-architect** : Modélisation, architecture logicielle, diagrammes (PlantUML).
- **senior-fullstack** : Développement stack complète.
- **site-architecture** : Planification de l'arborescence et routage de sites webs.
- **spec-driven-workflow** : TDD de haut niveau via rédaction de specs.
- **spec-to-repo** : Bootstrapping automatisé d'un dépôt d'après une spec textuelle.
- **tech-stack-evaluator** : Comparaison de technos et calcul de TCO.
