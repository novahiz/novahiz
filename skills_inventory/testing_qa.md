# 🧪 Testing & QA

- **api-test-suite-builder** : Création automatisée de tests d'API.
- **browser-automation** : Scraping, bots, et manipulation DOM sans framework lourd.
- **browserstack** : Configuration des tests cross-browser cloud.
- **fix** : Résolution de tests instables (flaky tests).
- **focused-fix** : Réparation globale d'une "feature" précise.
- **migrate** : Migration de Selenium / Cypress vers Playwright.
- **playwright-pro** : Toolkit complet de tests automatisés e2e.
- **senior-qa** : Expertise en stratégies de QA et automatisation complète.
- **tdd-guide** : Pilotage strict du développement par les tests (Red/Green/Refactor).
- **testrail** : Synchro et gestion des suites de tests TestRail.
- **troubleshooting** : Aide au débogage via logs et diagnostics.
