# Checklist du frontmatter (10 points)

1. [ ] name correspond au dossier (kebab-case, ≤64)
2. [ ] description : action + déclencheurs, ≤1024, sans XML
3. [ ] license présente (Apache-2.0 recommandé)
4. [ ] metadata (author, version)
5. [ ] Pas de secrets ni de balises XML dans le frontmatter
6. [ ] Corps du SKILL.md sous 500 lignes (ou divisé proprement)
7. [ ] Références au niveau 1, liées avec pointeurs explicites
8. [ ] Scripts exécutables avec aide intégrée (--help)
9. [ ] Pas de chemins absolus machine
10. [ ] Mémoire cohérente et citée (si mémoire utilisée)
