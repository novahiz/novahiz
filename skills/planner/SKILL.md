# Novahiz Planner Skill

Le Planner est utilisé pour décomposer toute tâche complexe en sous-tâches atomiques.

1. Identifiez la fonctionnalité.
2. Identifiez les fichiers affectés.
3. Écrivez le plan dans un artefact `implementation_plan.md` si requis par le mode.
4. Écrivez les TODOs dans `task.md`.
5. Procédez à l'exécution étape par étape.
