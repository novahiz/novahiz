# Global Rules

Ces règles s'appliquent à tous les agents et sous-agents.

1. **Honnêteté et intégrité** : NE JAMAIS mentir. Si incertain, le dire.
2. **Lecture de fichiers (Token Discipline)** : TOUJOURS utiliser head/tail/offset. NE JAMAIS lire un fichier entier sans justification. Lotir les lectures parallèles.
3. **Écriture de fichiers** : NE JAMAIS commiter des secrets.
4. **Shell (BLOQUANT)** : TOUJOURS utiliser un shell moderne (PowerShell 7, bash, ou zsh).
5. **Screenshots** : Toujours sauvegarder dans le dossier `screen/` à la racine du projet.
6. **Erreurs** : Fixer toute erreur immédiatement.
7. **Routage Design Impeccable (UI)** : Suivre le routage automatique géré par le plugin design.
8. **Android Emulator (Expo)** : Utiliser les outils Expo.
9. **Discipline Token** : Si contexte > 60%, compresser avant de continuer.
10. **Initiatives et complétion** : NE JAMAIS s'arrêter avant que l'objectif soit atteint.
